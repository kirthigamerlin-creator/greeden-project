**Greeden - HTML Prototype**
**Overview**
This project is a front-end prototype built using HTML and Tailwind CSS. The goal of this prototype is to create a website using Tailwind CSS without creating external css.

**Features**
Responsive design
Navigation bar
Hero section
About us section
Best seller section
Customer reviews section
News letter section
Footer

Our products page
Contact us page

Mobile-friendly layout

Technologies Used
HTML5
Tailwind CSS
